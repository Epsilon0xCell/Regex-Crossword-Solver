Regex-Crossword-Solver

A Python solver that parses each row and column regex with a PLY grammar, turns the puzzle into an SMT problem, and solves it with Z3. Backreferences are supported, so puzzles using groups and references such as \1 can be solved, including rectangular puzzles. Codename: Red Robin.

The package

The crossword/ package does the solving. crossword.py provides solve_crossword(rows, cols, rows2=None, cols2=None) and solve_regex(regex, length). It returns a list of rows of single characters, or None when Z3 finds no solution. The optional second clue sets, rows2 and cols2, add regexes the same grid must also satisfy.

The parser pair

regex_parser.py is the PLY lexer and parser, implementing the grammar recorded in grammar.md. regex_solver.py builds the Z3 expression for one regex at a fixed length. Repetition counts may start at zero: a{0}, a{0,0}, a{0,} and a{0,2} all parse and solve, covered by the test_brace_zero test. Character sets are parsed in sorted order, so parse trees do not depend on hash randomization.

The shell menu, stated honestly

ultimate-regex-solver.sh is an interactive Bash menu, and it is not needed to use the bundled solver. Option 2 runs the bundled custom-solver.py with your normal account; there are no raised privileges anywhere in the menu. Options 1, 3 and 4 download other people's external projects at one pinned commit each, show the file list, and stop: they do not run the downloaded code, and they do not delete a download folder that is already there. Option 1 no longer runs its download with Python 2, because that external MIT Mystery Hunt project is Python 2 era code that should be read before anyone runs it. The script changes into its own folder first, so the example is found wherever it is launched from.

Gate checks

Requirements are Python 3 (verified on Python 3.12) plus two packages:

pip install ply z3-solver
python3 custom-solver.py
python3 -m unittest discover -s crossword -t .

Verified on Python 3.12 with ply 3.11 and z3-solver 5.3.3: 60 tests pass, including under different PYTHONHASHSEED values. The suite is noisy by design: the solver tests print the regexes and the Z3 expressions they build. PLY also writes parser.out and parsetab.py next to the package when it runs; make clean removes those byproducts.

Margin note from the repo: mistyped row counts solve the wrong shape, so check the clue counts before blaming the solver.
