Regex-Crossword-Solver

A Python solver that parses row and column regular expressions through a PLY grammar, converts the grid into an SMT problem, and returns the letters Z3 finds, backreferences such as \1 included. This page is the apron movement log: each guided arrival gets one row and a result.

The package

crossword.py offers solve_crossword with rows, cols, and the optional second clue sets rows2 and cols2, plus solve_regex for a single pattern at a fixed length. It returns a grid of single characters, or None when no solution exists.

Grid or None

The parser pair

regex_parser.py holds the lexer and grammar described in grammar.md. regex_solver.py builds the Z3 expression for one pattern. Repetition counts may start at zero, and character sets are parsed in sorted order so parse trees stay stable.
